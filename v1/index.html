Hash a local file

Zero-Harm / Anti-Inversion
Consequential feature fusion should preserve informed consent, reversibility where feasible, privacy boundaries, accessibility, source provenance, appeal/review pathways and explicit distinction between observed facts, modeled estimates and AI-generated inference.
